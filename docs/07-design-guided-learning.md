## 一个模块怎么学（All-in-One）

1. **看视频**：用一句话说明要解决什么工程问题、具体输入输出是什么。
2. **读源码**：找入口、调用链、数据结构、错误处理。ChatGPT 可以在对话中贴关键代码片段（确实取得原代码或明确写“教学化示例”）并逐段解释；不要求反复跳转资料。
3. **补理论**：只从 AI Agent Book 补本节知识点，解释原理、对比实现、给图示与练习。
4. **实践**：先跟随课程复现，再解释、预测结果、尝试局部改动/故障调试。ZCode 可辅助重复性劳动，但由学习者确认核心逻辑与测试边界。
5. **验收**：对应小林 Coding 的原题链接 + 1–2 个注明“改编”的本项目追问。用自己的话联系项目代码回答，不让 AI 提前给个人作业标准答案。
6. **归档**：在 Notion 自由记录思考、笔记和疑问；GitHub 记录本人有权分享的设计、可复现实验、测试与真实进度。无固定模板、日更量或 Commit KPI。

## 不把思考外包给 AI

- 看懂 ≠ 自己能解释；跑通 ≠ 已掌握。分开记录**运行/工程证据**和**理解/迁移能力**。
- 每学到一个重要模块，至少能解释“它解决什么问题、输入输出、调用链、正常与错误路径、为什么采用这种设计”。
- 在看过示范后逐步减少提示：预测输出 → 自己解释 → 小改动 → 独立定位错误 → 讨论替代方案。课程阶段**不强制从零手搓每个模块**，也不让 ZCode 自动完成全部理解过程。
- 没运行过的测试标“未测”；不会回答的题标“待复习”；改编面试题不能冒充原题。可按 T0 / T+3 / T+14 抽查，但不以打卡压倒学习。
- 使用 ChatGPT 时讲清楚“我看到的源码”与“基于经验推测/教学化改写”的边界；真实路径、版本、测试输出必须经过核实。
- 阶段 B 开始自主设计后，才强化独立规格、接口、状态图、故障分支、Mock/pytest、Trace/Eval 与可审查的工程提交；当前不要让这些步骤妨碍跟课学习。

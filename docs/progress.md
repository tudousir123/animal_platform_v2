## 记录原则

- **学习进度**：看过哪节视频、读了哪个源码模块、自己能解释什么。
- **工程证据**：具体运行命令、测试输出、实际文件/版本；未测填未测。
- **独立理解**：不用 AI 直接代答，能解释流程、辨认异常并修改代表性代码，关联小林题能自己说清。
- **归档**：Notion 自由记学习笔记；GitHub 只存有分享权限的文档、自己的代码与验证证据。
- 不因计划已更新就给 Lab Agent 或 SalesPilot 填“代码完成”；旧 M0–M5 不再作为当前进度条。

# AutoCoach AI V3.1 · Agent 应用开发执行路线（2026-10-10 修订）

> **状态：当前执行版**。基于 V3.0 解冻后的局部修订；目标岗位确认为 **AI Agent 应用开发工程师**。保留原 C00–C14 编号、Python 自研 Agent Runtime、李博杰《深入理解 AI Agent》为 Agent 唯一主教材、汽车销售训练场景、毕业优先。原 [V3.0](autocoach-v3-frozen.md) 只作版本记录。

## 一、技能与项目交付

**第一阶段（简历 V1）：** Python 3.11+、LLM API、Agent Loop/ReAct、Tools、Context/Memory、RAG/MCP、Eval/Trace，加上**最小 FastAPI HTTP 服务**及 Python asyncio/测试/调试。C13 需做可调用服务而不只是 CLI/Streamlit；不引入 Django，不提前转 Go 或复杂数据库。

**第二阶段（简历 V2）：** Go、MySQL、Redis、系统设计、消息队列/分布式按岗位需要补强。系统设计与基础并发思想在 V1 中适量学习，避免零基础做 Agent 服务。

**统一执行闭环：** 需求 → 官方教材原文+官方实验 → 自主设计 → 小步编码 → pytest/Mock → 真实模型小样本 → 自动/人工评测 → Python+Agent 面试原题及项目追问 → 提交。不得把计划值写成实测值。

## 三、面试训练（三条线，不增加 Commit）

1. **Agent 核心**：小林 coding Agent/RAG/工具调用/大模型工程专题对应原题（原题链接须逐题核对），理解并能指向本项目代码。
2. **Python 高频优先池约25个主题**：GIL；线程/进程/协程；asyncio 事件循环/Task/超时取消；装饰器/闭包；垃圾回收/引用计数；可变对象和默认参数；dict/hash；浅深拷贝；迭代器/生成器/yield；is/==；OOP/MRO；上下文管理器；异常处理；async 生成器与阻塞 I/O 等。**这不是牛客全站118题的逐题客观频次统计，而是基于公开面经主题和 Agent 应用匹配度选择的学习优先池。**以 [小林 Python 题库](https://xiaolincoding.com/interview/python.html) 为源，在 `docs/interview/Cxx.md` 中补确切原题链接，不能把自拟追问冒充原题。
3. **服务工程**：FastAPI、HTTP、ASGI/WSGI、SSE、测试、并发上限、超时/重试/取消，放到 C11–C14 和对应小步实验。Go/MySQL/Redis PDF 留到第二阶段。

## 四、可追踪验收数据（每个 Commit 记录）

- **工程门禁（必须通过）**：需求与设计、正常+异常测试、Mock 可复现、真实依赖错误处理、运行说明、可指出代码位置的面试答辩、无密钥。约定不能测试的功能必须明确标“未验证”。
- **Agent 样本（建议目标）**：工具30例、客户/端到端20例、故障至少10例；角色约束与任务完成率按明确分母统计。
- **RAG 样本**：C06 首轮至少10条人工核验，后续拓展至50题目标；报告 Recall@5、引用支持率、拒答和失败分布；小样本不得以单一百分比夸张代表泛化能力。
- **评分**：至少两条好/坏对照由人检查证据，后续逐步扩大。模型 Judge 不能单独自证有效。
- **性能与成本**：TraceID、模型/提示词版本、调用路径、各步耗时、Token与成本估计、终止原因；对照试验固定模型、数据集、采样配置。
- **学习与答辩量表**：0无法解释、1能复述、2能讲原理、3能结合自己代码讲设计取舍、4能应对异常追问。每 Commit 核心问题建议至少3/4；C14 抽样20题至少16题达3/4且关键模块无完全失语。这是课程目标而不是已取得的成绩。
- **时间记录**：预计/实际分钟、阻塞原因、复盘；建议每周15–20小时，6周为乐观、8–10周为保守规划估计，毕业论文优先。进度按验收推进，不按日期强行提交。

推荐追踪字段：`docs/progress.md` 的 Commit 状态、投入时长、测试数、原题掌握度、模型版本、结果产物与 Git SHA；`eval/cases/` 与 `eval/results/` 从 C00 起逐步新增。样本数据和性能只能在真实运行后填写。

## 五、C13 最小 API 契约（建议，最终依代码设计确定）

```text
GET  /health
POST /sessions                 创建会话/选择客户场景
POST /sessions/{id}/messages   发送学员消息，返回客户应答
POST /sessions/{id}/finish     结束训练，生成结构化评估
```

Agent 核心代码不依赖 FastAPI；CLI 和 HTTP 使用同一服务层；SSE 作为加分项而非第一版强制门槛。测试包含成功、非法输入、缺失会话、模型超时、模型凭据缺失与重启行为（只承诺已实现的恢复机制）。

## 六、版本变更边界

V3.1 是 V3.0 的**有证据增量修订**，不是推翻重做。未经实际成果和目标岗位反馈，不继续新增框架、组件或换业务主题。下一步仍从 **C00** 开始，按 [Commit 任务书](autocoach-commit-playbook-v3.md) 执行，并优先采用本文的更新验收要求。
